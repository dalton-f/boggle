# Boggle

An online version of the game Boggle, a word game in which players try to find as many words as they can from a grid of lettered dice.

## Features

- **Variety of Selection Methods**: Drag, click, or use your keyboard to select words in the grid

- **Grid Size Settings**: Change your settings to play with the standard 4x4 grid, all the way up to a 6x6 grid

- **Timed Game Modes**: Play against the clock for an added challenge

- **Word Validation & Dictionary Support**: Instant feedback on valid words

- **Mobile-Friendly Design**: Optimised for touch screens and smaller devices

- **Accessibility Options**: Full keyboard navigation and high-contrast support
